# V5.6 optics and edge-adaptive upscaling

User reported approximately 150 FPS on Extreme after V5.5 (hardware, render distance and resolution not supplied). No new GPU capture requested. Baseline V5.5 complete GLSL build, compatibility and aislop passed.

- DoF default strength .25 (was .5); radius coefficient 32 (was 48), 1080p cap 8 (was 14); deadband .008; smaller foreground rings across disk/separable paths. Old saved strength values remain valid, but the base formula is gentler.
- Idle defocus is enabled whenever DoF is enabled, unless DOF_IDLE=0. Existing camera state atlas adds a 16-byte third texel; no new image slot. Both manual and automatic modes supported when the existing camera-state capability gate passes. Idle is a camera-motion/FOV/held-item proxy, not input detection; static interactions, camera bob or paused screens can behave differently. Default 8-second delay, 2-second target ramp, .65 s onset / .12 s recovery half-life. Idle softens the full scene with the same four taps as optional peripheral optics; no extra pass, no additional taps when neither effect is active. Peripheral optics is separately opt-in, radial blur and subtle chromatic difference, not darkening. Color sample source is pre-DoF HDR; blending may partially override stronger ordinary DoF near silhouettes. UI is unaffected.
- EDGE_TAAU is a LumenWeave original algorithm inspired by the concepts in AMD GPUOpen FSR 1 (https://gpuopen.com/fidelityfx-superresolution/) and FSR 2 (https://gpuopen.com/manuals/fidelityfx_sdk/techniques/super-resolution-temporal/). No imported AMD code, no official FSR claim. Uses existing four spatial donors, directional luminance gradient, bounded detail restoration, color-change reactive proxy, current low-contrast envelope reuse, and geometry/depth/normal rejection. Native opaque donor metadata is read once, and near coplanar donors may skip inverse projection. Water/DH retain original geometry checks. Fixed projection remains fixed. No motion vectors for independently moving objects or native reactive mask. No additional pass or image. May improve edges, but new arithmetic and tighter history rejection can also cost GPU time or change temporal quality.
- Only Ultra/Extreme enable EDGE_TAAU by preset; others explicitly reset it on switching. Natural/Potato/Low/Standard set PERCEPTUAL_GI/MULTIRATE_VOLUME/SSR_FOOTPRINT=2 and APPROX_REUSE=1; binary cache and SH already max. No other existing profile values changed. Lens effects remain personal independent settings.

Run `python tools/optics_upscale_sim.py` for deterministic CPU proxy: idle timing at 30/60/144/240 Hz, bounded scalar 2x2 vertical-edge and affine ramp reconstruction, and depth blur radius. Synthetic edge result is not game image quality, speed or actual FSR equivalence. Actual GPU runtime and motion stability require user visual testing.
