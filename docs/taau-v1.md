# Full-scene TAAU V1 implementation contract (research)

Iris legacy depth buffers remain window-size. Render a sub-rectangle by transforming every geometry clip position, not by resizing an isolated colortex attachment. For render size R and display size D, scale s=R/D; clip.xy'=s*clip.xy+(s-1)*clip.w. Native render UV = outputUV*s; inverse = renderUV/s. Use integer R dimensions and exact pixel-center mapping at odd sizes. Jitter must be in render-pixel units, projected before viewport transform. Clear unused border and never sample it.

Required integration: (1) audit ALL geometry entries including vanilla fallback, terrain/entities/hand/sky/weather/clouds/DH and translucent ordering; (2) shared render/output grid for projection, G-buffer fetch, depth and native/DH Hi-Z, shadows remain unscaled; (3) reconstruct output history via depth, normals, disocclusion and reactive water/emission mask; (4) post effects consume output grid or explicitly map depth; (5) validate resize, FOV, teleport, frame-rate, mod geometry, edges and thin foliage. 
P62 implements an effect-level half-res spatial reconstruction plus existing full-resolution temporal history, but does not establish full-scene geometry TAAU. See Iris docs rendering and Photon public implementation for viewport-scale design context, no code copied. Keep full resolution until real pipeline validation.

An isolated forward-only experiment now exists in experiments/taau; build with `python tools/package.py --taau-probe`. It uses the integer native grid, full-resolution temporal output, depth/normal disocclusion checks and reactive hand/transparency rejection. It deliberately does not claim full production integration.

## Production integration V4: scene HDR resolve
`SCENE_TAAU_SCALE` (50/67/75/85/100, default 100) now scales the existing post-translucency composite viewport, uses a phased integer source lattice, and resolves into the existing full-resolution TAA history. Native depth, geometry, G-buffer, DH and reflection grids are deliberately unchanged. GI, clouds, water, DH and exposure remain available. The scene/volume composition pass and both spatial volume compute grids are reduced. The corresponding history and reconstruction readers use the same integer active dimensions, including the solar visibility reader. Earlier geometry and deferred lighting remain native. This is an incremental production path, not the full geometry TAAU of the experiment. All later post effects use the resolved full-resolution radiance and native depth. No hardware validation yet.

Focused validation: `python tools/check_shaders.py --v4-focused`; the full matrix and all packaging checks remain mandatory. Scene HDR and volume scaling are deliberately separate from any future geometry viewport scaling.

## V5 geometry TAAU
`GEOMETRY_TAAU_SCALE` controls the true pre-resolve active rectangle. Native and DH geometry share a logical UV grid, jittered by a centered eight-phase sequence in active pixels. Deferred, AO/GI, Hi-Z, rough SSR, water, cloud and scatter passes use active integer extents; screen-texture normalized fetches convert logical UV into storage UV. Shadow and voxel world grids stay native. Full-resolution composite1 reconstructs color from depth/normal/medium-compatible low-grid donors and reprojects into native history. Reactive water and radiance changes attenuate history, sky retains rotation reprojection, unsupported geometry rejects temporal history. Post-process depth reads map into the active grid; automatic DOF uses actual active center depth. No claims of real GPU compatibility until in-game Iris/DH validation. All texture allocations remain native-sized for matching depth and attachment layout; this reduces shaded pixels rather than guaranteeing VRAM savings.
Preset scales: Natural/LowExposure/HighExposure/Potato/Low/Standard 100, Medium 67, High and Ultra 75, Extreme 85. Geometry scale takes precedence over independent V4 scene-only scale. All new controls have Chinese and English labels.

Iris program fallback coverage: https://shaders.properties/current/reference/programs/gbuffers/ — entities, hand, particles and specialized draws inherit the existing basic/textured/lit/water/terrain programs, whose shared vertex/fragment functions now use the active grid. Shadow programs remain separate. Mod-specific bypass rendering and actual DH viewport conventions still require a game session.
