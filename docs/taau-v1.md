# Full-scene TAAU V1 implementation contract (research)

Iris legacy depth buffers remain window-size. Render a sub-rectangle by transforming every geometry clip position, not by resizing an isolated colortex attachment. For render size R and display size D, scale s=R/D; clip.xy'=s*clip.xy+(s-1)*clip.w. Native render UV = outputUV*s; inverse = renderUV/s. Use integer R dimensions and exact pixel-center mapping at odd sizes. Jitter must be in render-pixel units, projected before viewport transform. Clear unused border and never sample it.

Required integration: (1) audit ALL geometry entries including vanilla fallback, terrain/entities/hand/sky/weather/clouds/DH and translucent ordering; (2) shared render/output grid for projection, G-buffer fetch, depth and native/DH Hi-Z, shadows remain unscaled; (3) reconstruct output history via depth, normals, disocclusion and reactive water/emission mask; (4) post effects consume output grid or explicitly map depth; (5) validate resize, FOV, teleport, frame-rate, mod geometry, edges and thin foliage. 
P62 implements an effect-level half-res spatial reconstruction plus existing full-resolution temporal history, but does not establish full-scene geometry TAAU. See Iris docs rendering and Photon public implementation for viewport-scale design context, no code copied. Keep full resolution until real pipeline validation.

An isolated forward-only experiment now exists in experiments/taau; build with `python tools/package.py --taau-probe`. It uses the integer native grid, full-resolution temporal output, depth/normal disocclusion checks and reactive hand/transparency rejection. It deliberately does not claim full production integration.

## Production integration V4: scene HDR resolve
`SCENE_TAAU_SCALE` (50/67/75/85/100, default 100) now scales the existing post-translucency composite viewport, uses a phased integer source lattice, and resolves into the existing full-resolution TAA history. Native depth, geometry, G-buffer, DH and reflection grids are deliberately unchanged. GI, clouds, water, DH and exposure remain available. The scene/volume composition pass and both spatial volume compute grids are reduced. The corresponding history and reconstruction readers use the same integer active dimensions, including the solar visibility reader. Earlier geometry and deferred lighting remain native. This is an incremental production path, not the full geometry TAAU of the experiment. All later post effects use the resolved full-resolution radiance and native depth. No hardware validation yet.

Focused validation: `python tools/check_shaders.py --v4-focused`; the full matrix and all packaging checks remain mandatory. Scene HDR and volume scaling are deliberately separate from any future geometry viewport scaling.

## V5 geometry TAAU
`GEOMETRY_TAAU_SCALE` controls the true pre-resolve active rectangle. Native and DH geometry share a logical UV grid, jittered by a centered eight-phase sequence in active pixels. Deferred, AO/GI, Hi-Z, rough SSR, water, cloud and scatter passes use active integer extents; screen-texture normalized fetches convert logical UV into storage UV. Shadow and voxel world grids stay native. Full-resolution composite1 reconstructs color from depth/normal/medium-compatible low-grid donors and reprojects into native history. Reactive water and radiance changes attenuate history, sky retains rotation reprojection, unsupported geometry rejects temporal history. Post-process depth reads map into the active grid; automatic DOF uses actual active center depth. No claims of real GPU compatibility until in-game Iris/DH validation. All texture allocations remain native-sized for matching depth and attachment layout; this reduces shaded pixels rather than guaranteeing VRAM savings.
Preset scales: Natural/LowExposure/HighExposure/Potato/Low/Standard 100, Medium 67, High and Ultra 75, Extreme 85. Geometry scale takes precedence over independent V4 scene-only scale. All new controls have Chinese and English labels.

Iris program fallback coverage: https://shaders.properties/current/reference/programs/gbuffers/ — entities, hand, particles and specialized draws inherit the existing basic/textured/lit/water/terrain programs, whose shared vertex/fragment functions now use the active grid. Shadow programs remain separate. Mod-specific bypass rendering and actual DH viewport conventions still require a game session.

## V5 compilation regression
The full GLSL matrix is partitioned into six deterministic program-link shards in CI. Each linked vertex/fragment pair stays together; capability and projection matrices and standalone compaction probes run on shard zero. The focused matrix runs separately; packaging requires every shard and the focused job to succeed. Local unsharded CLI behavior remains unchanged. Scene-only and native projection cases explicitly select native geometry to avoid silently testing geometry TAAU instead. Personal camera options (motion blur, DOF and lens ghosts/star) remain independent of quality presets while still available in the shader menu.

## V5.1 runtime regression
Fixed projection now also means zero jitter in reduced geometry. The same function drives raster, ray reconstruction, volume reprojection and post depth. Spatial reconstruction and full-resolution temporal accumulation remain enabled; dynamic subpixel TAAU remains selectable. Fixed mode trades subpixel sample diversity for stability. Settled unchanged voxel tiles preserve support without re-reading/writing their 64 direct/diffuse cells; dirty or still transitioning tiles update, camera movement invalidates the skip. Static output history fast path uses the actual native pixel, and the current donor is not reconstructed twice. The probe's Iris format metadata uses the same comment convention as the main pack. Real GPU timings and visual confirmation remain required.

## Camera autofocus V2
Reference inspected: MakeUpUltraFast commit `65c3ac0818120c97d2b7ad6686b3318f5c14f24e`, `shaders/lib/blur.glsl` (smoothed center depth, bounded continuous radius, two opposite mip samples), `shaders/lib/config.glsl` (`centerDepthHalflife=0.66` ticks). Conceptual reference only, no imported code. LumenWeave uses nine reticle samples of hand-free world depth, robust median with supported center selection, temporal optical-power history with asymmetric half-lives and dead band in texel 1 of the existing camera state. Exposure remains texel 0. The half-resolution DoF resolve uses four depth-compatible donors instead of expensive per-pixel full gather fallback. No new image slot; state is enabled without auto exposure if budget permits. Legacy native fallback uses loader-smoothed depth; reduced geometry without persistent state uses manual focus rather than sampling the wrong center. Personal settings remain independent of presets. In-game performance and focus pull video remain unverified.

Additional camera/performance work: CoC radius scales by output height, the extra foreground ring fades into the primary disk, Balanced uses at most 12 depth/color donor locations per half-resolution pixel (Cinematic 16, Fast 4). The native resolve uses four depth-compatible donors rather than recomputing the disk; legacy GI-owned buffer configurations retain a bounded direct gather. Voxel history precomputes decay factors per workgroup, bypasses FP16 quantization for equal targets, and tests the center tile before scanning the support halo. The full-resolution light temporal fallback skips mathematically zero-weight chromatic adaptation. These are work-count improvements, not measured FPS.

The full-resolution DoF composite now uses continuous CoC-weighted reconstruction rather than replacing even sharply focused pixels with the half-resolution color. Near defocused compatible donors can cover a sharp background at silhouettes; farther donors cannot cover a sharp foreground.

## V5.3 movement-aware voxel history
The old smooth-light cache updated all N³ cells whenever the integer camera position changed. Two disjoint parity banks now store local 4³ tile support/transition flags. For unchanged targets, exact old tile mappings reuse settled history (including lit tiles); misaligned mappings skip only if all 1–8 overlapping previous tiles are both empty and settled. Entered cells, dirty targets, nonconsecutive frames and pending transitions still run the original per-cell update. A skipped tile writes current parity metadata, so repeated motion cannot observe stale data. Support includes alpha as well as RGB. Rain column moves to slice 2N+4, and the atlas grows by 2N² RGBA16F texels (144 KiB at N=96, 256 KiB at N=128); no extra image slot. CPU simulations count per-cell history work, not FPS or physical memory traffic.

Direct voxel shading now shares edge fade, ring address and seam interpolation between raw and smoothed fields while preserving independent support checks, including removal tails. Material SSR rejects zero-contribution and out-of-range rays before material decoding and rain ripple normal work. Neither changes preset sampling ceilings. Numerical equivalence tests cover dual-field interpolation and independent support flags.
