# Iris independent voxel production and shadow cache feasibility
Sources: [Iris ordering](https://shaders.properties/current/reference/shadersproperties/ordering/), [Iris voxelDistance](https://shaders.properties/current/reference/constants/voxeldistance/), [Iris shadowIntervalSize](https://shaders.properties/current/reference/constants/shadowintervalsize/), [Iris ShadowRenderer](https://github.com/IrisShaders/Iris/blob/26.1/common/src/main/java/net/irisshaders/iris/shadows/ShadowRenderer.java), [Iris RenderRegion mixin](https://github.com/IrisShaders/Iris/blob/26.1/common/src/main/java/net/irisshaders/iris/compat/sodium/mixin/MixinRenderRegion.java), [Epic VSM](https://dev.epicgames.com/documentation/unreal-engine/virtual-shadow-maps-in-unreal-engine).
## Pure shader pack
Reversed culling deliberately supplies off-screen local geometry; gbuffers only sees camera-visible geometry. Shadowcomp consumes existing GPU data, not chunk events. shadowIntervalSize snaps spatial position; it is not a temporal redraw interval. A persistent image can cache visibility samples, but cannot prevent Iris submitting its shadow draw. Do not disable shadow terrain or retain stale seed cells without a complete producer.
## Loader extension proposal
Use section build/upload/unload revisions as the primary event stream, supplemented by light-level and material changes. Build a compact per-section seed palette/run list from immutable section snapshots, not every render vertex. Upload only changed sections and entering/exiting slabs, preserve a world-coordinate toroidal grid and explicit deletion records. On dimension change, resource reload, teleport or missed revisions perform full rebuild. Publish monotonic epochs before prepare; only disable reverse-culling/vertex injection after complete region coverage is acknowledged. Retain fallback for unmodified Iris.
For shadows, separate static terrain and moving entities/wind/cutout. Start with texel-snapped directional static cache keyed by light matrix, section revisions, caster bounds and render settings. On translation with unchanged light basis scroll cached tiles, invalidate exposed/changed tiles; on rotation or light direction change rebuild unless a quantified approximation is accepted. Render dynamic casters separately, compose minimum depth per receiver. Preserve alpha/cutout and animated vegetation semantics. Page invalidation must use both old and new projected caster bounds, handle unloaded chunks and DH ownership. Avoid full-map copy where tiled depth or layered compare suffices. Existing Iris separate Sodium shadow lists cache draw batches, not depth contents. Implement as version-specific companion mod/Iris patch; no current pack-only event API provides this contract.
## Benchmark
Collect CPU section rebuild/upload, shadow draw and GPU compute timings, tile hit ratio and invalidation count, before changing defaults. Compare camera still, rotating, translating, daylight cycle, block changes and moving entities; compare shadow visibility and voxel seed field against full rebuild.
