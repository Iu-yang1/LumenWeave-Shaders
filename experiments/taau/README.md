# TAAU experimental probe
Build with python tools/package.py --taau-probe. This is a separate forward-only diagnostic shaderpack, not LumenWeave's full rendering pipeline. It maps geometry into an integer lower-left render rectangle at 50/67/75/85/100%, then reconstructs a full-resolution history using current geometry, depth/normal checks, reactive transparent/hand rejection and neighborhood clipping. No native GPU timing or game load has been verified; no DH, GI, PBR, advanced water, clouds or production compatibility claims. It exists to validate the difficult render-grid contract before production integration.
